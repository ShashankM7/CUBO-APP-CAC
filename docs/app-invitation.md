# App invitations

Account > Support > Invite someone opens a shareable invitation above Help and feedback.
This is a public app recommendation, not a family membership invitation.

- Personalizes only with the current profile display name.
- Always links to https://cubo-app-cac.pages.dev/, including from Expo or a preview.
- Includes iPhone Safari installation steps (Open as Web App when available) and Android guidance.
- Copy writes the complete message. If blocked, the preview remains selectable.
- Share opens the device/browser share chooser. Available apps depend on the device.
- Cancellation does not send anything or show an error. Unsupported sharing suggests Copy.
- No contacts lookup, Firebase writes, referral tracking, or server messaging.

## Direction contract

THESIS: Extend Account with a clear, private invitation action, not a referral campaign.
OWN-WORLD: Reuse CUBO Manrope, green accent tokens, existing light/dark surfaces and rounded-sheet language.
STORY: Preview the exact message, copy or choose a sharing app, then return to Account.
FIRST VIEWPORT: Title and close control above a scrollable message; Copy and Share remain below it with safe-area spacing.
FORM: Narrow code-led extension of the established Account surface; no concept seed or new visual identity.
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

No design-system replacement or raster assets. Existing design files are preserved.
Automated coverage: name fallback, production URL, setup text, copy/share failure and cancellation, native adapter and row placement.
Phone share-sheet choices and physical iPhone rendering still require device testing.
